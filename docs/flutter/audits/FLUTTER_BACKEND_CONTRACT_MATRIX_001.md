### 1.2 Backend Owner Action List (What Must Be Available for End-to-End Local Dev)
1. **Confirm local Backend run command & `.env` profile:** Verify `uvicorn app.main:app --host 0.0.0.0 --port 8000` with `ENVIRONMENT=development` and `DATABASE_URL=sqlite:///./dermaire_dev.db` (or local Postgres via `docker-compose.yml` adjusted for `ENVIRONMENT=development` — note `docker-compose.yml:31` sets `ENVIRONMENT=production`, which requires a non-default `SECRET_KEY` and `AZURE_STORAGE_CONNECTION_STRING` for image uploads!).
2. **Decide image storage for local dev:** Either provide a dev/sandbox Azure Blob connection string (or Azurite setup instructions with private container `skin-records`) so `GET /api/v1/captures/{id}/image` returns real bytes, OR explicitly accept `storage: "not_persisted"` during Phase 1 local smoke tests.
3. **Password reset testing in local dev:** Confirm whether `EXPOSE_PASSWORD_RESET_TOKEN=false` remains default (with ACS email creds or DB inspection) since PR #7 intentionally discards client-side debug tokens.
4. **Safety policy rollout coordination (post-first-run):** Keep `SAFETY_POLICY_ENFORCE=false` until an approved public HTTPS `text/plain` policy document and its SHA-256 are published and PR #7 is merged with `DERMAIRE_VERIFIED_POLICY=true`.
